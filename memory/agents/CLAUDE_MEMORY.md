## Standing notes

### 2026-06-10 — Startup sequence
Always load, in order: `memory/global/PROJECT_CONTEXT.md` →
`agents/claude/ROLE.md` → this file → the active task file.

### 2026-06-10 — Logging habit
Append to the execution log after each meaningful step, not at the end.
Sessions can stop without warning; the log is the recovery point.
